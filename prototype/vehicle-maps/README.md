# Vehicle maps prototype

Open `index.html` directly in a current desktop or mobile browser. The viewer
has no build step or network dependencies for the maps. It links to manuals and
reference photography when available.

The catalog stores relative footprints and approximate extrusion heights for each
vehicle variant. All coordinates are illustrative. Physical measurements and
on-vehicle tracking tests are required before using them as AR anchors.

Keep photos that lack a documented license on their original sites. For a local
preview with an approved photo, set `photoFile` and `aspectRatio` for a catalog
entry and use coordinates already calibrated to that image and crop.
